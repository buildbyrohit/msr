### ⚡ Quick Setup

Open **MobiStream** ➔ **Settings** ➔ **Extensions** ➔ **Add Repository** (`+`), and type any shortcode:

```text
msr
```
> *(Alternative shortcodes: `jeet`, `rohit`, `mobistream`)*

#### Manual URL:
```text
https://raw.githubusercontent.com/buildbyrohit/msr/builds/repo.json
```
