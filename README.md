## ⚡ Instant Installation Guide

### 🌟 Method 1: Instant Shortcode (Recommended)
You don't need to type the full long URL!

1. Open **MobiStream** (or CloudStream).
2. Go to **Settings** ➔ **Extensions** ➔ **Add Repository** (`+` button).
3. In the repository URL box, simply type:
   ```text
   msr
   ```
4. Enter any name (e.g., `MSR`) and tap **Download / Add**.
5. All premium extensions will load instantly!

---

### 🔗 Method 2: Direct Manifest URL
If using external apps or manual input, paste the raw manifest URL:
```text
https://raw.githubusercontent.com/buildbyrohit/msr/builds/repo.json
```
